How to run the website from Admin
1. Job Postings → Careers page
Admin → Job Postings → New Job → set Status = Active → Save. It appears on Careers instantly.
2. Applications + email alert
When someone applies, it saves to Supabase and an email goes to uxonicdigitalmedia@gmail.com. Review in Applications.
3. Website Content
Website Content edits homepage hero, contact details, Join Our Team. Saved in Supabase → live site.
4. Contact messages
Homepage Contact form → Supabase + email notify → Messages.
Local URL: always use http://127.0.0.1:5501 with npm run dev — not Live Server.
